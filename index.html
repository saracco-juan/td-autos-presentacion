Integración continua

En cada push y pull request · GitHub Actions

  • BackendFormato con Pint y tests con cobertura
  • WebLint, tests con cobertura y build
  • MobileLint, typecheck, tests y build de Android
  • SonarQube CloudAnálisis estático, cobertura y menos de 3 % de código duplicado
